# 🔐 Secure Login System

A secure user authentication web application built using Python, Flask, SQLite, and bcrypt.

## 🚀 Features
- User Registration
- Secure Password Hashing using bcrypt
- User Login Authentication
- SQLite Database Integration
- Input Validation
- Session Management
- Logout Functionality
- SQL Injection Protection using parameterized queries

## 🛠️ Technologies Used
- Python
- Flask
- SQLite
- bcrypt
- HTML
- CSS

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Obalesha-M-123/Secure-Login-System.git
   ```

2. Open the project folder:
   ```bash
   cd Secure-Login-System
   ```

3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```

4. Set a secure secret key in PowerShell:
   ```powershell
   $env:SECRET_KEY="your-generated-secret-key"
   ```

5. Run the application:
   ```bash
   python app.py
   ```

6. Open your browser:
   `http://127.0.0.1:5000`

## 📌 Project Objective
To develop a secure login system that protects user accounts using password hashing, input validation, and session management.
